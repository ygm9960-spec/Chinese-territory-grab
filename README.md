# 송~청 동아시아 땅따먹기 FINAL+ GitHub Pages용

이 폴더의 `index.html`은 수업용 최신 통합본입니다.

포함 기능
- 메인/후반전/결과 BGM 3곡 HTML 내부 내장
- 객관식·주관식·미니게임 문제은행 내장
- 권역 미션 자동 표시
- 숨겨진 중국사 미니 이벤트(+1점)
- 핵심지역 해금: 개척권역 통일 + 일반 영토 4칸
- 중원 쟁탈권역: +10점
- 모둠 현황 확대 및 최신 UI

## GitHub Pages 업로드
1. 저장소 최상위(root)에 `index.html`과 `.nojekyll`을 올립니다.
2. Settings → Pages → Build and deployment → Deploy from a branch
3. Branch: `main`, Folder: `/(root)` → Save
4. 배포 주소는 보통 `https://아이디.github.io/저장소이름/` 입니다.

※ BGM은 브라우저 자동재생 정책 때문에 첫 클릭 이후 재생될 수 있습니다.
※ 별도 mp3 파일은 필요하지 않습니다. 3곡이 index.html 안에 base64로 포함되어 있습니다.
